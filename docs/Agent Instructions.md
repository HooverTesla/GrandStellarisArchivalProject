### How to use docs
1. Please be aware docs are a work in progress
2. These are generally considered to be to-do lists with descriptions and notes for the future as opposed to complete documentation, these will probably get deleted when a feature is complete
	1. Dead links should be considered as no-work-needed for the moment
	2. Empty pages should be considered placeholders for human organization
	3. These are not to replace Readme's outside of the docs folder. Think more like construction notes than usage notes
3. Docs are built in Markdown in Obsidian so a few features apply
	1. "[[]]" is referencing a file by that name
4. Formatting at the head of files are basic information that most or all files will have
	1. icon: Name of image
		1. may be a description if I cannot find the exact file name or it's already the correct one
	2. sub-tabs
		1. This means this page should have a sub-navigation bar below the main one, these should be small and basic but match the general theme of the main one with the listed tabs
	3. Location: Where this file will be accessible from
		1. Most will be listed in the databank but a few will be in the nav-bar or other odd locations
5. Generally work top down, the highest file should be the high level instructions, with linked files be more specific to them.
		1. e.g. Databank has some generic information about formatting and styles and there will be too many specific types of data to be specific about each one. 
	1. This isn't always true, sometimes it's just linking files to show where links should be attached or located. 
		1. An example is the empire tab, ethics, civics, etc will have a custom formatting and linking there but the actual civics or ethics etc pages shouldn't take any formatting from that page unless specifically requested
6. Images folder will have a couple example images when I can't accurately describe something. 
	1. These should be considered as guidelines but when contradictory to specific instructions or details in these docs, the docs and instructions take priority.
